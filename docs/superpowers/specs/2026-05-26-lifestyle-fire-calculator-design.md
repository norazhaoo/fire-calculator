# 生活方式 FIRE 计算器设计

## 背景

这个产品的核心不是让用户先理解 FIRE、提现率、通胀和投资收益，而是让用户描述自己想要的生活。系统把生活方式输入翻译成年支出、风险缓冲、目标资产、预计达成年限和一份可读报告。

第一版面向中国用户，但主线仍然是 FIRE 估算，不把社保养老金、三金或退休政策作为核心。养老金、房租收入、副业收入等可以作为可选的退休后收入抵扣项。

## 用户目标

用户应该能回答：

- 我想过这种生活，大概要准备多少钱才能 FIRE？
- 保底版、安全版、富足版分别需要多少钱？
- 哪些生活选择最影响 FIRE 目标？
- 如果我改变旅游、孩子教育、医疗大病、居住或每月投资，结果会怎么变？
- 我离目标还有多少年？

## 核心体验

用户先选择估算版本，再进入问卷。

```text
+--------------------------------------------------+
| 你想先估算哪一种 FIRE 生活？                       |
+--------------------------------------------------+

[ 保底版 ]
必要生活稳定，不追求消费升级，重点是尽快自由。

[ 安全版 ]
维持体面生活，有医疗、大病、父母、孩子等缓冲。

[ 富足版 ]
生活选择更宽裕，旅行、教育、医疗、家庭支持都更充分。
```

选择后进入分步问卷。问卷结束后进入 Review，用户确认或修改后生成报告。

## 三个版本

### 保底版

保底版回答“最低程度不用上班也能活得稳”。它包含必要生活、基础医疗、低频旅游和小额风险缓冲。

典型假设：

- 饮食以日常在家和普通外食为主。
- 居住按当前城市基础成本或用户输入成本。
- 旅游低频，偏国内或短途。
- 大件消费按较长更换周期折旧。
- 医疗包含医保外日常支出、基础商业保险和小额大病备用金。
- 孩子教育默认公立路线，如果用户选择不要孩子则排除。

### 安全版

安全版回答“维持当前想要的生活，不被一次坏年份打乱”。它包含真实生活预算、较完整风险缓冲、正常旅游、大件更新、父母责任和孩子教育。

典型假设：

- 饮食、居住、交通接近用户当前或目标生活。
- 旅游按用户真实频率和目的地估算。
- 医疗包含商业医疗险、重疾险、门诊牙科眼科、体检、慢性病或家庭健康支出。
- 大病缓冲覆盖自费缺口、康复、护理、护工和异地就医相关成本。
- 家庭责任包含父母支持、父母医疗和养老护理。
- 孩子教育按用户选择的公立、民办、国际学校、课外班和留学路线估算。

### 富足版

富足版回答“自由之外还有选择权”。它包含更宽裕的旅行、教育、医疗、父母支持、居住升级和生活升级预算。

典型假设：

- 更高频或更长途旅行。
- 更好的居住、服务、兴趣和社交预算。
- 孩子教育可包含国际学校、海外夏校、留学或更高课外投入。
- 医疗可包含私立医疗、海外或跨城就医、更高护理预算。
- 父母养老和大病支持更充足。
- 使用更保守的提现率或更高风险缓冲。

## 问卷输入模型

### 基础信息

- 当前年龄
- 所在城市
- 家庭结构：单人、伴侣、家庭
- 是否有孩子或计划孩子数量
- 当前可投资资产
- 每月可投资金额
- 目标 FIRE 年龄，可选
- 预期年化收益率
- 通胀率
- 安全提现率

### 日常生活

- 每天在家吃饭预算
- 外卖或餐厅预算
- 每周聚餐次数
- 咖啡、奶茶、零食预算
- 日用品、衣服、会员订阅
- 社交、人情、礼物、节日支出

### 居住

- 房租或房贷
- 物业、水电燃气、宽带
- 家具家电折旧
- 装修、维修、搬家
- 是否计划换城市或退休后搬到低成本城市

### 交通

- 公共交通和打车
- 是否养车
- 车险、油费或电费、停车、保养
- 购车或换车周期

### 旅游和体验

- 一年旅游几次
- 国内、亚洲、欧美、海岛或长途
- 每次几天
- 几个人去
- 穷游、舒适或高端
- 是否有长期旅居

### 大件和兴趣

- 手机、电脑、相机、游戏设备更换周期
- 家具家电更换周期
- 运动、课程、乐器、摄影、收藏
- 宠物、宠物食品、宠物医疗

### 孩子

- 是否要孩子
- 几个孩子
- 托育、月嫂、保姆
- 公立、民办或国际学校
- 课外班、夏令营、兴趣班
- 大学和留学
- 孩子医疗和保险

### 家庭责任

- 每月或每年支持父母金额
- 父母医疗备用金
- 父母养老、护工、陪诊
- 兄弟姐妹或家庭突发支持

### 医疗、保险和风险

- 商业医疗险
- 重疾险
- 意外险
- 寿险
- 日常门诊
- 牙科、眼科、体检
- 慢性病长期用药
- 大病自费缺口
- 康复、护理、护工
- 异地就医交通和住宿
- 收入中断缓冲
- 生活费安全垫

## 版本切换和答案继承

版本有明确顺序：

```text
保底版 -> 安全版 -> 富足版
```

答案需要记录来源：

```text
user       用户亲自填写
inherited  从低版本继承
derived    从高版本推导
default    系统默认值
```

### 从低版本升级到高版本

如果用户先完成保底版，再切到安全版或富足版：

- 已回答的通用问题自动带入。
- 低版本已有的问题在高版本中预填，来源标记为 inherited。
- 高版本新增问题继续询问。
- 高版本可按比例生成建议值，例如旅游、大病缓冲、父母支持、孩子教育预算。
- 所有继承和建议值都可编辑。

例子：

```text
保底版已填：
日常吃饭 ¥3,000/月
旅游 ¥12,000/年
大病缓冲 ¥200,000

升级到富足版：
日常吃饭 ¥3,000/月        inherited，可编辑
旅游 ¥60,000/年           default，可编辑
私立医疗预算 ¥30,000/年   default，可编辑
父母护理预算              新问题
孩子留学                  新问题
```

### 从高版本降级到低版本

如果用户先完成富足版，再切到安全版或保底版：

- 不重新问卷。
- 直接进入 Review。
- 系统根据低版本规则从高版本答案推导低版本值。
- 富足版独有的项目不删除原始答案，只是在低版本计算中排除或折减。
- Review 页面展示 derived 来源，用户可以修改。
- 用户确认后生成对应版本报告。

例子：

```text
富足版已填：
欧美旅游 ¥120,000/年
国际学校 ¥300,000/年
私立医疗 ¥60,000/年

切到保底版 Review：
旅游 ¥15,000/年         derived，可编辑
孩子教育 公立路线       derived，可编辑
医疗和大病 ¥250,000     derived，可编辑
```

## Review 页面

Review 是提交报告前的最后一步。它要让用户知道哪些值来自自己、哪些值来自继承、哪些值是系统估算。

```text
+--------------------------------------------------+
| 安全版 Review                                    |
+--------------------------------------------------+
| 吃饭预算        ¥4,500/月      user               |
| 居住预算        ¥9,000/月      user               |
| 旅游预算        ¥45,000/年     inherited，可编辑   |
| 大件折旧        ¥24,000/年     default，可编辑     |
| 大病缓冲        ¥600,000       default，可编辑     |
| 父母支持        ¥36,000/年     user               |
| 孩子教育        民办路线       user               |
+--------------------------------------------------+

[ 修改 ] [ 生成报告 ]
```

## 计算模型

第一版使用透明的规划型估算，不追求官方精算。

```text
年度基础支出 =
饮食 + 居住 + 交通 + 日常 + 医疗保险 + 娱乐

年度周期支出 =
旅游 + 大件折旧 + 节日人情 + 家庭支持 + 孩子教育 + 医疗风险摊销

年度总支出 =
年度基础支出 + 年度周期支出

FIRE 目标资产 =
年度总支出 / 安全提现率
```

退休后收入可作为可选抵扣：

```text
净年度 FIRE 支出 =
年度总支出 - 养老金 - 房租收入 - 副业收入 - 其他被动收入

FIRE 目标资产 =
净年度 FIRE 支出 / 安全提现率
```

达成年限使用当前资产、每月投资和预期年化收益率逐年模拟。模拟直到资产达到目标资产，或超过最大模拟年限。

## 报告输出

报告以用户当前选择版本为主，同时展示三档对比。

```text
你的 FIRE 估算

主版本：安全版
目标资产：¥8,900,000
预计达成：16 年
预计 FIRE 年龄：46 岁

三档对比：
保底版   ¥5,800,000   预计 11 年
安全版   ¥8,900,000   预计 16 年
富足版   ¥13,500,000  预计 23 年

年度生活成本拆分：
居住       28%
孩子教育   22%
饮食       13%
医疗风险   12%
旅游       10%
家庭责任   8%
其他       7%

最大影响项：
1. 孩子教育
2. 居住成本
3. 医疗和大病缓冲
4. 旅游频率
5. 父母养老支持
```

报告需要包含：

- 主版本 FIRE 目标资产
- 三档目标资产对比
- 预计达成年限和 FIRE 年龄
- 年度生活成本拆分
- 最大影响项
- 可行动建议，例如每月多投多少钱、减少哪个项目会提前几年
- 关键假设，例如提现率、年化收益率、通胀率

## 状态和数据结构

第一版可以用前端本地状态，不需要账号或后端。

核心实体：

- `ScenarioTier`: `baseline`, `safe`, `abundant`
- `Question`: 问题定义、所属版本、输入类型、默认值规则
- `Answer`: 问题 ID、值、来源、最近编辑版本
- `LifestyleModel`: 按类别汇总的年度支出模型
- `FireResult`: 目标资产、达成年限、年度投影、影响项
- `Report`: 当前版本报告和三档对比

模块边界：

- 问题定义模块：管理问卷结构和版本可见性。
- 答案继承模块：处理升级、降级、来源标记和默认值。
- 支出模型模块：把答案转换为年度支出。
- FIRE 计算模块：计算目标资产、达成年限和年度投影。
- 报告模块：组织主报告、三档对比和影响项。
- UI 模块：负责问卷、Review、报告展示。

## 边界情况

- 用户不知道某项金额：允许使用系统建议值，并标记为 default。
- 用户不打算要孩子：隐藏孩子教育细项，报告说明已排除。
- 用户没有当前资产或每月投资：仍生成目标资产，但达成年限显示无法达成或需要补充投资输入。
- 年支出小于退休后收入：目标资产可为 0，但报告要提示结果高度依赖收入稳定性。
- 安全提现率为 0 或负数：禁用报告生成并提示修正。
- 预期收益率过高：允许输入，但报告提示这是高风险假设。
- 医疗大病预算为空：安全版和富足版必须给出默认建议值。
- 从富足版降级：保留原始富足答案，低版本报告只使用降级后的 derived 值。

## 非目标

第一版不做：

- 官方养老金精算。
- 税务精算。
- 账户体系和云同步。
- 银行、券商或支付数据导入。
- AI 自动读取账单。
- 医疗保险产品推荐。
- 投资建议或具体资产配置推荐。

## 测试策略

第一版至少需要覆盖：

- FIRE 目标资产公式。
- 年度支出汇总。
- 达成年限模拟。
- 保底、安全、富足三档结果生成。
- 从低版本升级到高版本时，答案继承并继续询问新增问题。
- 从高版本降级到低版本时，直接进入 Review 并生成 derived 值。
- Review 修改值后，报告重新计算。
- 无孩子、无车、无房、无当前资产等常见分支。
- 医疗大病默认值参与安全版和富足版计算。

## 成功标准

- 用户可以先选择保底版、安全版或富足版。
- 用户可以完成一个版本的生活方式问卷。
- 用户切换版本时不会重复填写已经回答的问题。
- 用户可以在 Review 页面看到并编辑所有关键假设。
- 系统可以生成主版本报告和三档对比报告。
- 报告能清楚说明 FIRE 数字来自哪些生活方式选择。
